Ik heb gewerkt aan het toepassen van de huisstijl van de opdrachtgever en het ontwerpen, maken en gebruiken van een styleguide. Het doel van dit onderdeel is om de website een consistente uitstraling te geven, zodat kleuren, lettertypes en componenten overeenkomen met de gewenste huisstijl.

Ik heb samen met mijn team een centrale styleguide opgezet in Figma en vertaald naar een gedeelde CSS-stylesheet die in de website en formulier-pagina wordt gebruikt. Hierdoor kan ik en anderen binnen het project consistente stijlen toepassen en hergebruiken.

## Kenmerken
<!-- Bij Kenmerken staat welke technieken zijn gebruikt en hoe. Wat is de HTML structuur? Wat zijn de belangrijkste dingen in CSS? Wat is er met Javascript gedaan en hoe? Misschien heb je een framwork of library gebruikt? -->

Voor het ontwerpen en toepassen van de huisstijl heb ik gebruikgemaakt van:

- Figma voor het visualiseren van de stijlregels en componenten.

- CSS voor het implementeren van de stijlregels in de website.

- HTML om de gestileerde componenten correct te structureren.

Ik heb gelet op consistente kleuren, lettertypes, spacing en componenten zoals knoppen en formulieren. Door het gebruik van een centrale styleguide blijft het ontwerp uniform en overzichtelijk, ook bij toekomstige uitbreidingen van de website.

Het resultaat is een website die volledig voldoet aan de huisstijl van de opdrachtgever en een herbruikbare styleguide die het werk aan de website vergemakkelijkt.
